# Terapeuta Regina

![Status](https://img.shields.io/badge/status-em%20desenvolvimento-yellow)

Este site foi desenvolvido com o propósito de servir como um portfólio profissional da terapeuta Regina Olbre Prohmam.

## Sobre o projeto

Inicialmente, este site foi desenvolvido como projeto final para a disciplina de **Experiência Criativa: Navegando pela Engenharia de Software**, mas também funciona como uma entrega profissional e funcional para apresentação dos serviços da terapeuta.

O objetivo do projeto é apresentar a profissional, seus serviços, informações de contato e depoimentos de forma clara, acessível e responsiva.

## Funcionalidades

- Formulário de contato
- Botão de contato
- Cabeçalho interativo
- Rodapé
- Introdução da profissional
- Descrição dos serviços
- Página de depoimentos
- Responsividade para diferentes tamanhos de tela

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript
- Git/GitHub

## Aprendizados

Durante o desenvolvimento do projeto, aprendemos a levantar requisitos, analisar a estrutura de um site de forma técnica, adaptar a interface de acordo com as necessidades do cliente e aplicar responsividade em páginas web.

Além disso, o projeto permitiu praticar a organização de arquivos, o uso de HTML e CSS na construção de páginas, a publicação do site pelo GitHub Pages e o trabalho em equipe utilizando Git e GitHub.
